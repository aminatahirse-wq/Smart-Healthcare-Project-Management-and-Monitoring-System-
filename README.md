🏥 Smart Healthcare Project Management and Monitoring System

A Python-based desktop application developed to plan, execute, monitor, and control software development projects for a network of five hospitals.
The system provides an interactive Graphical User Interface (GUI), database management, project scheduling, cost monitoring, Earned Value Analysis, quality management, and risk control.

Project Overview

The Smart Healthcare Project Management and Monitoring System (SPMS) is designed to help project managers efficiently manage healthcare software development projects.
The system manages project activities such as patient appointments, laboratory reports, doctor schedules, online consultations, and hospital billing.
It provides tools to manage project scope, requirements, schedules, resources, budgets, changes, defects, and risks. It also performs automatic calculations to monitor project performance and generate progress reports.

Project Objectives

Manage project initiation and integration.
Organize project requirements and scope.
Generate a Work Breakdown Structure (WBS).
Schedule activities and allocate resources.
Monitor project costs and budgets.
Calculate Earned Value Management (EVM) indicators.
Manage change requests and their impacts.
Track software defects and quality checks.
Identify and prioritize project risks.
Generate project progress reports.

 Main Features

1. Project Initiation and Integration Management
Create and manage project charter.
Define objectives, stakeholders, and scope.
Maintain project budget and deadline.
Manage project milestones and team responsibilities.
Record project status and closure information.

2. Scope Management and WBS

Add, update, prioritize, and approve requirements.
Generate hierarchical Work Breakdown Structure.
Manage project deliverables and work packages.
Submit and evaluate change requests.
Prevent unapproved requirements from entering the approved scope.

3. Schedule and Resource Management

Create and manage project activities.
Assign tasks to team members.
Define task durations and dependencies.
Calculate activity start and finish dates.
Identify delayed and impacted activities.
Display project schedules through a Gantt chart.

4. Cost Management and Earned Value Analysis

Estimate activity costs.
Track actual project expenditure.
Calculate project budget and cost performance.
Automatically calculate EVM indicators.

5. Quality Management and Risk Control
Record and manage software defects.
Assign defects to team members.
Monitor defect resolution status.
Maintain quality inspection checklists.
Calculate risk scores using likelihood and impact.
Display a Risk Prioritization Matrix.
Provide a Process Decision Program Chart (PDPC).

6. System Integration, Validation and Reporting

Integrate all modules into one application.
Store project information in an SQLite database.
Validate user inputs.
Maintain consistency between project records.
Generate project progress reports.
Display pending change requests, delayed activities, budget status, and unresolved critical defects.
